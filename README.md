# Career Assistant

A personal Python-based application designed to help university students discover and organise internship and entry-level employment opportunities.

## Project Overview

Career Assistant is a local web application built using Python and Streamlit. It aims to streamline the job-search process by helping users identify relevant opportunities, compare job requirements against their skills, and prepare tailored application documents.

## Features

- Search job listings through supported public job-board APIs.
- Discover internships, traineeships, junior IT positions, and administrative opportunities.
- Rank job opportunities based on skills, experience requirements, location, and working arrangements.
- Generate editable, role-tailored CVs and cover-letter drafts.
- Track applications and review opportunities before submitting.

## Technologies

- Python
- Streamlit
- REST APIs
- JSON
- SQLite
- python-docx

## Project Status

Personal project under active development.

The application runs locally. Job applications are reviewed and submitted manually, and personal information is not included in this public repository.
